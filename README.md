📅 Itinéraire détaillé
Jour 1 – Édimbourg : randonnée modérée + ville 

Prendre un premier panorama : Arthur’s Seat (ouSalisbury Crags ). 
Trajet (Inverkeithing → Édimbourg) Train : Inverkeithing → Edinburgh Waverley (direct, ~26 min en moyenne).
En sortant de Waverley : marche 20–30 min vers Holyrood Park (ou bus local selon ton hébergement). Itinéraire à pied – Arthur’s Seat (modéré) Point de départ conseillé : entrée de Holyrood Park côté Palace of Holyroodhouse / Queen’s Drive. 1) Entrer dans Holyrood Park et suivre les panneaux “Arthur’s Seat”. 2) Monter progressivement par le sentier principal (large, fréquenté). 3) Au col : continuer au sommet si la météo est OK (rafales faibles) ; sinon, demi-tour ici = déjà très belle vue. 4) Descente par le même chemin (le plus simple) ou boucle douce via les sentiers inférieurs.
